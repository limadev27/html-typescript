## Testar
Extraia o ZIP e abra esta pasta no VS Code. Clique com o botão direito no index.html e escolha Open with Live Server (extensão Live Server). Os JavaScripts já estão compilados.
Para recompilar: instale TypeScript com `npm install -g typescript` e execute `tsc` na raiz desta pasta. Para acompanhar alterações: `tsc --watch`.
