## Testar
Extraia o ZIP e abra esta pasta no VS Code. Clique com o botão direito no index.html e escolha Open with Live Server (extensão Live Server). Os JavaScripts já estão compilados. Não abra por file://.

Para recompilar: instale TypeScript com `npm install -g typescript` e execute `tsc` na raiz desta pasta. Para acompanhar alterações: `tsc --watch`.

## Antes de entregar
Substitua Seu Nome nos HTMLs e Seu Nome Completo neste README. Crie um repositório público chamado pweb-ts-estruturas e envie todos os arquivos, inclusive .js e .js.map. Faça commits ao longo das suas alterações.
No GitHub: Settings > Pages > Deploy from a branch > main > / (root) > Save.
